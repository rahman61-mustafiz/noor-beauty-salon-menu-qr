# Noor Beauty Salon - QR Code Digital Menu System (NOOR QR)

## 📱 Project Overview
Noor Beauty Salon's complete digital QR menu system with a luxury dark theme, fully hosted on GitHub Pages. Customers scan a QR code to view the 24-page HTML menu with all services and pricing in BDT (Bangladeshi Taka).

---

## 🎨 Design Features

### Visual Design
- **Background**: Ash tone gradient (#1f1f1f to #232323) — premium, not pure black
- **Primary Color**: Gold (#d4af37) — ALL text, prices, headings, borders
- **Accent Color**: Wine red (#a52a2a) — opening hours banner
- **Logo**: SVG embedded inline (gold) on every page, no external dependencies
- **Tables**: 1-2px gold borders, organized pricing
- **Special Packages**: Card-style layout with large price displays (Bridal, Pre-Wedding)

## 🔄 How to Update the Menu

### Step 1: Edit the File
Open `noor_complete_menu_with_logo.html` in any text editor (VS Code, Notepad++, etc.)

### Step 2: Make Changes
- **Prices**: Find the price value and update it (always in gold #d4af37)
- **New Service**: Add a new `<tr>...</tr>` row to the appropriate table
- **Remove Service**: Delete the `<tr>...</tr>` row
- **Layout**: Modify CSS in `<style>` section if needed

### Step 3: Upload to GitHub
1. Go to https://github.com/rahman61-mustafiz/noor-beauty-salon-menu-qr
2. Click **"Add file"** → **"Upload files"**
3. Drag and drop `noor_complete_menu_with_logo.html`
4. Commit message: e.g., *"Update bridal package pricing"*
5. Wait 1–2 minutes — changes go live automatically

### Step 4: Verify
- Visit the live URL in your phone browser
- Refresh (Ctrl+R or Cmd+R)
- Changes should appear

### Print Tips

- Resolution: 300 DPI for quality print
- Placement: High-traffic areas (reception, waiting area, entrance)
